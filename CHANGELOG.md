# Changelog

## 0.1.0

- First release.
- Click and drag with the hammer to build a run of stakewalls (regular and Dvergr), with right-click corners.
- Each piece is set level with the terrain on its lower edge, so nothing floats and only the uphill edge is buried.
- Three fill modes for sections that aren't a whole number of pieces long, switchable with Q/E while dragging.
- Materials, stamina, tool wear, skill gain and player stats are applied per piece, the same as vanilla building.
